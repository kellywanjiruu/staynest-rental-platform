# StayNest - Short-Term Rental Platform

Professional Airbnb-style MVP using Node.js, Express, PostgreSQL, and Vanilla JavaScript.

## Features in this phase

- Property cards on home page
- Backend API for listing properties
- Database schema for users, properties, availability, and bookings
- Seed data for demo listings

## Setup

1. Copy `.env.example` to `.env` and set your `DATABASE_URL`.
2. Create database and run:
   - `db/schema.sql`
   - `db/seed.sql`
3. Install dependencies:
   - `npm install`
4. Start development server:
   - `npm run dev`

Open `http://localhost:3000`.
